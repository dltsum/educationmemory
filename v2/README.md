# 三层记忆辅导台 (v2)

面向中小学个性化辅导的三层记忆系统：**保存 → 整理 → 压缩**，带实时可视化界面（网页版 + 桌面版）。

## 3 步上手（非技术用户）

1. 安装 Python（python.org，勾选 Add to PATH）
2. 三端任选：
   - **桌面快捷方式**（最省事）：桌面「三层记忆辅导台」图标，双击即用
   - 网页版 `python server.py` → http://127.0.0.1:8766
   - **Electron 桌面客户端**（推荐展示用）：`electron/启动桌面客户端.vbs` 双击（**免 cmd 黑窗**，自动拉起后端 sidecar + 开窗口；首次需 `cd electron && npm install`）；改了代码/卡死时用 `electron/重启客户端.vbs` **一键重启**（自动杀残留旧后端和旧窗口再干净启动）。备用：`启动桌面客户端.bat`
   - tkinter 备选：`python app_ctk.py`（customtkinter）/ `python app_tk.py`
3. API key 已在服务端预填（演示用），打开即可对话；改 key/模型点 **⚙ 配置**

按 记忆.docx 调研材料 + 前沿论文实现（references/记忆_extracted.txt 留档），右栏下拉即换整理/压缩提示词与回填格式，可同一档案对比：

### 演示方案（ZPD 支架式）

- 左下角"演示方案"下拉：5 个学生（档案 800-980 字：知识图谱+前置DAG、Felder性格、提问频次+周明细、错题记录、评语、目标）。页面打开默认选中 S1
- **选中方案即自动开始**：清空上一轮 → 该生档案作为首条消息直接注入对话（气泡内嵌展示，AI 当场应答），输入框保持空白
- 胶囊点击=挂上附件卡（出现在输入框上方，可点 ✕ 取消；可挂多张）；发送时附件全文随输入文本一起发出，气泡里以引用块展示：**紫色胶囊=ZPD 支架式提问链**（①诊断边界→②边缘任务→③支架请求→④撤架迁移）；**绿色胶囊 📄=整套真实试卷弹窗**（原卷分节结构+全题量+保留原题号，逐题「＋挂上」；来源：重庆渝中五下期末/2024中考一次函数/三年级期末/七年级有理数乘除真题汇编/北师大六下圆柱圆锥卷；依赖图形/图片公式的题诚实标注未收录，绝不虚构）；白色胶囊=错题开场/多轮追问/档案探针

### 配置表盘（⚙ 配置）

- **模型**：内置 OpenCode 全部 26 个模型下拉（Grok 4.6 / GLM-5.x / GPT 5.6 Luna / Kimi K3·K2.x / LongCat / MiMo / MiniMax / Muse Spark / Qwen3.x / DeepSeek V4 / Hy4·Hy3，按提供商分组），也可用"自定义模型 ID"覆盖
- **推理变体**（OpenCode 内置变体，随模型提供商自动切换选项）：Anthropic 系 `high`(默认)/`max`；OpenAI 系 `none/minimal/low/medium/high/xhigh`；Google 系 `low/high`；其他模型给全量备选，不生效时留"默认"
- **请求参数**：`max_tokens`（reasoning 模型必须 ≥4000）、`temperature`（留空=模型默认）
- **上下文创建方法**：自定义 `buildContext`（见下）

## 三层记忆是什么

| 层 | 触发方式 | 做什么 | 用不用 AI |
|---|---|---|---|
| 📝 **记忆保存** | 每句对话自动 | 过滤无用信息（重复、纯客套"好的谢谢"、AI 样板开场白），**其余全部保留**。不是"只挑特定信息"，而是"只扔明确的垃圾" | 不用（本地算法） |
| 🗂 **记忆整理** | 点按钮 | AI 把零散记忆整理成分节的结构化文档（画像/学习进展/错题/偏好/事件/待办），合并重复、标注纠正 | 用（1 次调用） |
| 🗜 **记忆压缩** | 点按钮 | AI 把结构化文档压成电报式高密度摘要（`|` 分隔、`→` 表因果），实测压到 1/20 | 用（1 次调用） |

右侧记忆面板**实时显示**当前记忆；点"整理"/"压缩"后内容即时变换，带高亮动画和压缩率提示（如 `9558→1435, -85%`）。回答时自动使用最优层：有压缩用压缩，没压缩用整理，都没有用原始保存。

## 自定义上下文方法（给开发者/智能体）

配置弹窗里的 `buildContext` 是唯一需要按需重写的方法，浏览器内执行的 JS：

```js
({memory, history, question, system}) => messages数组
```

- `memory`：当前最优记忆文本（压缩>整理>原始）
- `history`：`[{role,content}]` 全部对话
- 默认实现 = system人设 + 记忆块 + 最近4轮 + 新提问
- 填入自己的函数即完全接管上下文组装；留空恢复默认

## HTTP API（接自己的前端）

| 端点 | 说明 |
|---|---|
| `POST /config` | `{api_key, base_url, model}` |
| `POST /chat` | `{messages, question, turn_no}` → `{reply, memory, saved}` |
| `GET /memory` | 三层记忆全量快照 + 统计 |
| `POST /organize` | 触发记忆整理 |
| `POST /compress` | 触发记忆压缩 |
| `POST /reset` | 清空记忆 |

## 实测数据（MathDial 真实对话 + 1.5k 字符学生档案，两模型）

| 层 | 字符数 | 回忆准确率 | 幻觉 |
|---|---|---|---|
| 原始保存 | ~9,300 | 100% | 0 |
| 整理版 | ~1,150（-88%） | 100% | 0 |
| 压缩版 | ~440（-95%） | 94–100% | 0 |

唯一丢失案例：压缩版丢了"母亲猫毛过敏"细节，但模型正确回答"档案没有记录"而非编造。

## 注意

- opencode go 网关对 **urllib 直连会 403**（系统代理问题），本后端已用 `requests`，勿改回 urllib

- reasoning 模型需 max_tokens≥4000，否则回答为空
