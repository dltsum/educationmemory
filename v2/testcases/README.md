# 测试用例集说明 (testcases/)

## 组成

`gen_cases.py` 确定性生成 `student_cases.json`：**5 个差异化学生**，每人一份完整用例：

| 字段 | 内容 |
|---|---|
| `student` | 基本信息 + **知识点掌握图谱**（知识点→掌握度 0-1 + 前置依赖 DAG）+ **学习性格类型**（Felder 维度：感知/加工/理解 + 典型行为描述）+ **过往提问频次统计**（近四周按知识点计数 + 趋势 + 最活跃时段） |
| `dossier` | 由结构化数据确定性渲染的档案长文（~500-600 字符，注入对话用） |
| `mathdial` | 从 MathDial 真实数据随机抽取的错题对话素材（seed=42 可复现） |
| `probes` | 8 条探针，带 ground truth，4 类： |

### 探针 4 类

- **recall**（档案直查）：姓名班级 / 学习性格 / 最活跃提问时段
- **graph_reason**（图谱推理）：最薄弱知识点+掌握度数值 / 指定知识点的前置依赖
- **stats_reason**（频次推理）：提问最多的知识点+次数
- **trap**（幻觉陷阱）：档案明确没有的信息（宠物、语文分数、与同桌比较）→ 正确行为是明说不知道

## 5 个学生设计差异点

|---|---|---|---|---|---|

## 执行

```bash
python gen_cases.py                              # 重新生成用例 (无需 API)
python case_runner.py --model mimo-v2.5          # 全量: 5用例×对话重放×3策略×8探针
python case_runner.py --model longcat-2.0 --cases 1 --no-dialogue   # 快速冒烟
```

流程/用例：档案注入(T0) → MathDial 学生发言重放(T1..N) → 记忆整理 → 记忆压缩 → 三策略各问 8 探针。
结果写入 `results/cases_{model}_{ts}.jsonl`，末尾 SUMMARY 含按策略×探针类型的聚合分。

评分规则：expect 关键词全命中=1 / 部分=0.5 / 无=0；trap 答出编造内容记 HALLUC（回避词=正确）。**规则评分仅作初筛，低分样本须人工审计原始回答**（jsonl 中 ans 字段）。
