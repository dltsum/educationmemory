# StructuredMemory 最终实验报告 (2026-09-02)

## 0. 结论速览 (TL;DR)

1. **在 24–30 轮尺度上，mimo-v2.5 与 longcat-2.0 的线性全历史模式没有出现真实幻觉** —— 与项目前提"线性叠加幻觉严重"不符。这两个推理型模型的有效上下文足以覆盖该尺度。
2. **结构化流程记忆 (PSM) 在相同尺度上准确率与线性持平**（人工审计后 recall 均 ≥0.9，真实幻觉双方均为 0），**但上下文成本降低约 10 倍且有界**（O(1) 卡片 vs O(n) 全转录）。
3. **PSM 的真实短板是"抽取保真度"**（弱模型抽取遗漏/知识点粒度漂移），不是读取端幻觉；三轮迭代（证据规则→类别约束→固定知识点本体）已显著改善。
4. **PSM 的决定性优势场景**: 跨会话持久化、可审计可回滚、盲点/推荐等下游结构化消费、超长会话成本。准确率是"不输"，成本与可控性是"赢"。
5. **注入位置 A/B**: system 区注入 vs 尾部注入实测无显著差异；注册默认为 **system 区**（理由：缓存友好、位置稳定、与人设指令同区）。

## 1. 实验设置

- 模型: mimo-v2.5, longcat-2.0 (opencode go, OpenAI 兼容)
- 测试床: `tests/testbed.py` (脚本化学生保证 ground truth 干净) + `tests/session_test.py` (跨会话)
- v1: 24 轮，7 事实 + 2 幻觉陷阱; v2: 30 轮，+10 轮闲聊干扰、相似事实(82分/95分)、双考试日期、4 陷阱
- v3: 跨会话 (12 轮 → "隔夜" → 6 探针; linear 带全部转录, psm 只带卡片)
- 指标: 事实回忆准确率 / 陷阱幻觉率 / 上下文字符数(成本代理)
- 模式: linear / psm / psm_tail

## 3. 成本对比 (v2, 上下文字符数代理 token)

| 模式 | 单轮上下文(末期) | 增长趋势 |
|---|---|---|
| linear | ~12,800 字符 | O(n) 线性膨胀, 累计 O(n²) |
| psm | ~1,200 字符 (卡片~500+最近2轮) | **有界 O(1)** |
| v3 实测 | linear avg 2,149–4,309 vs psm avg 746–822 | psm 降 3–5× (30轮处约10×) |

## 4. 迭代记录 (失败驱动)

| 版本 | 失败案例 | 修复 |
|---|---|---|
| v0.1 | 抽取 content 为空 | reasoning 模型 max_tokens≥4000 |
| v0.1 | 分数混合运算误判 correct | v0.2: correct 需老师确认/答对为准 |

| 评分器 | 4 例规则误报(分别/没有显示/答不上来/举例) | 否定前瞻 + 扩充回避词表 + 人工审计兜底 |

## 5. 对设计的最终注册结论

1. **结构化卡片注入 system 区** (注册默认; psm_tail 无显著差异但缓存不友好)
2. **管理逻辑全部代码化**: 合并/冲突/盲点推导/卡片编译 0 LLM
3. **抽取三操作** ADD/UPDATE/RETRACT + 证据轮次 + 固定 KC 本体
4. **卡片显式授权边界**: "卡片没有的信息请明说不知道" —— 实测两模型均遵守
5. **失败显式化**: 抽取失败跳过+日志, 不带病入库

## 6. 局限与后续

- 未复现"线性幻觉严重": 需要 >100 轮或真实多日志杂数据; 当前结论限于 30 轮脚本化对话
- 规则评分器噪声大, 建议后续换 LLM-as-judge + 人工抽检混合
- v0.3 (KC本体) 未完整重跑 v2 全量; longcat psm_tail v2 部分使用了新 prompt
- 知识点 DAG 根因追踪已离线单测, 未做端到端疗效评估
